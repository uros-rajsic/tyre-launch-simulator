# Tyre Launch Simulator

A browser-based 3D tyre launch simulator.

## Run Locally

```bash
npm run dev
```

Then open:

```text
http://localhost:4174
```

## Deploy To Vercel

Import this repository in Vercel as a static site.

- Framework preset: Other
- Build command: leave empty
- Output directory: `.`

The game uses static `.glb` model files from `assets/models/`.
